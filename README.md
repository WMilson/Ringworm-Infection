> Задача из книги Д. Ван Тассела «Стиль, разработка, эффективность, отладка и испытание программ».

---

## 📖 О проекте

Приложение на **C# Windows Forms** имитирует процесс заражения клеток кожи стригущим лишаём.  
Каждая клетка может находиться в одном из трёх состояний:

- 🟢 **Здоровая** (белый цвет)
- 🔴 **Заражённая** (красный цвет)
- 🔵 **Невосприимчивая к инфекции** (голубой цвет)

Изначально заражена только центральная клетка.  
С каждым шагом времени заражённая клетка может заразить любого здорового соседа с вероятностью **0.5**.  
Через **6 единиц времени** заражённая клетка становится невосприимчивой, а ещё через **4 единицы** — снова здоровой.

## ✨ Возможности

- Ввод размера поля `n` (нечётное положительное число, не более 100).

- Автоматическое выполнение с настраиваемым интервалом (кнопка **«Старт/Пауза»**).
- Наглядное цветовое отображение состояний клеток.
- Отображение номера текущего шага в заголовке окна.
- Простая и понятная архитектура с разделением логики и интерфейса.

## 🎮 Использование

1. Введите **нечётное число** в поле ввода — это размер стороны поля `n`.
2. Нажмите кнопку **«Инициализировать»**.  
   Центральная клетка станет заражённой, остальные — здоровыми.
3. Для одного шага модели нажмите **«Шаг»**.
4. Для автоматического выполнения нажмите **«Старт»**.  
   Повторное нажатие (**«Пауза»**) останавливает процесс.
5. Наблюдайте за распространением инфекции по цветам клеток.

## 🧠 Как работает модель

### Правила

- Поле `n × n`, где `n` — нечётное.
- Начальное состояние: центральная клетка заражена.
- На каждом шаге времени:
  - Каждая заражённая клетка может заразить **любого здорового соседа** (8 направлений) с вероятностью **0.5**.
  - Если клетка заражена **6 единиц времени**, она становится **невосприимчивой**.
  - Если клетка невосприимчива **4 единицы времени**, она становится **здоровой**.
- Здоровая клетка может быть заражена только в том случае, если она ещё не болела (или уже потеряла иммунитет).

### Схема перехода состояний

```
Здоровая  ──(заражение, 0.5)──►  Заражённая
                                      │
                          6 единиц времени
                                      ▼
                                Невосприимчивая
                                      │
                          4 единицы времени
                                      ▼
                                   Здоровая
```

## 📂 Структура кода

| Файл | Назначение |
|------|------------|
| `InfectionModel.cs` | Логика модели: состояния клеток, подсчёт соседей, переход к следующему шагу. |
| `Form1.cs` | Интерфейс: обработка кнопок, таймер, отрисовка сетки. |
| `Form1.Designer.cs` | Автоматически сгенерированный код элементов управления. |
| `Program.cs` | Точка входа в приложение. |

### Класс `InfectionModel`

- Хранит двумерные массивы `states` и `timers`.
- Константы состояний: `Healthy = 0`, `Infected = 1`, `Immune = 2`.
- Метод `CalculateNextState()` возвращает новый объект `InfectionModel` — следующее поколение.
- Инкапсулирует все правила модели.

### Класс `Form1`

- Управляет визуализацией через `DataGridView`.
- Метод `RenderModel()` раскрашивает ячейки в зависимости от состояния.
- Кнопки и таймер вызывают `AdvanceGeneration()`.
